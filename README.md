One razor-sharp line, 200 characters or fewer, that gets you out of a pointless meeting: the last "quick sync" ran 94 minutes and ended by booking a second meeting.

## Run it

```sh
python3 main.py
```

The program writes the excuse to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
